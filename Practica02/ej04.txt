En un sistema matemático existen 5 procesos
worker que deben resolver en forma
colaborativa el procesamiento de un vector de enteros de tamaño N=1.000.000,
minimizando el tiempo de ejecución. Analice el problema y defina que distribución de trabajo
serán necesarios/convenientes para resolverlo de acuerdo al procesamiento a realizar en cada
item:
a) Se debe obtener la suma de todos los elementos del vector

Vector vector[N](int), sum_local[5]=([5]0); sem mutex = 1; int suma = 0; int aux = 0;

Process worker [id:0..4]{
	int i;
	while(true){
		P(mutex);
		if(aux >= N){
			V(mutex);
			break;
		}
		int i = aux;
		aux++;
		V(mutex);
		sum_local[id]+=i;
	}
	P(mutex);
	suma+=sum_local[id];
	V(mutex);
}
